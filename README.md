## 📌 Descripción del Proyecto
Este repositorio contiene el trabajo de investigación y desarrollo del **Equipo 39** para el Proyecto Integrador de la MNA. En esta primera instancia, el proyecto tiene un enfoque netamente investigativo centrado en el estudio, implementación y validación de **Redes Neuronales Informadas por la Física (PINNs - Physics-Informed Neural Networks)**. 

Las PINNs permiten incorporar ecuaciones diferenciales (leyes físicas) directamente dentro de la función de pérdida de una red neuronal, logrando aproximaciones precisas incluso con escasos datos de entrenamiento.

---

## 🎯 Objetivo General
Investigar la viabilidad, capacidad de convergencia y precisión de las arquitecturas de PINNs frente a problemas físicos modelados por ecuaciones diferenciales (ordinarias y parciales), sentando las bases teórico-prácticas para su aplicación en el sector industrial o científico.
